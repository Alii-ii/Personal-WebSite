### 已知边界

- 点赞已持久化到 `site_comment_likes`；未建立匿名身份的访客需先设置昵称后才能点赞。
- 根评论若已有其他用户回复会提示无法删除；如后续要求级联管理，需要数据库 RPC/管理员角色策略。
- 当前站长不自动获得删除他人评论的权限，删除权限严格按评论作者与 RLS 判断。
